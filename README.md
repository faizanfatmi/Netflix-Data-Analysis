# 🎬 Netflix Data Analysis

A complete Exploratory Data Analysis (EDA) project on the Netflix dataset using Python.  
This project focuses on analyzing Netflix movies and TV shows to discover trends, popular genres, ratings distribution, country-wise content production, and yearly growth patterns through data visualization.

---

## 📌 Project Overview

In this project, I performed:

- Data Cleaning & Preprocessing
- Handling Missing Values
- Exploratory Data Analysis (EDA)
- Data Visualization using Matplotlib & Seaborn
- Trend Analysis on Netflix Content

The analysis helps in understanding:
- Most common genres on Netflix
- Popular content ratings
- Movies vs TV Shows distribution
- Top countries producing Netflix content
- Year-wise growth of Netflix titles

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

# 📈 Key Insights

- Movies are more common than TV Shows on Netflix.
- TV-MA and TV-14 are the most frequent ratings.
- The United States produces the highest amount of Netflix content.
- Documentaries and International Movies are among the most popular genres.
- Netflix content increased rapidly after 2015.
